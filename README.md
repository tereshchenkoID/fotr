# Fate of the Ring

Браузерная сюжетная RPG по мотивам Средиземья. В игре три кампании, 18 героев и три вида испытаний. Монеты виртуальные. Сохранения работают в IndexedDB и доступны для экспорта в JSON.

## Запуск

Требуется Node.js 22.12+ и npm.

```bash
npm ci
npm run dev
```

Откройте локальный адрес из вывода Next.js. По умолчанию это [главная страница на порту 3000](http://localhost:3000/en/). Локали `en`, `ru` и `uk` доступны по отдельным адресам. Корневой маршрут ведёт на английскую версию.

| Команда                | Результат                                |
| ---------------------- | ---------------------------------------- |
| `npm run build`        | Сборка Next.js в `.next/`                |
| `npm run start`        | Запуск production-сборки                 |
| `npm run lint`         | ESLint для JavaScript и JSX              |
| `npm run lint:styles`  | Stylelint для SCSS                       |
| `npm run format`       | Форматирование JS, SCSS, JSON и Markdown |
| `npm run format:check` | Проверка форматирования и стиля          |
| `npm run test`         | Тесты Vitest                             |

Для локальной проверки production-сборки запустите `npm run build`, затем `npm run start`.

## Vercel

В [vercel.json](vercel.json) заданы пресет Next.js и команда `npm run build`. Для публикации подключите репозиторий проекта к Vercel. При наличии собственного домена задайте `NEXT_PUBLIC_SITE_URL` абсолютным URL без пути. Для canonical, Open Graph, robots и sitemap сборка использует эту переменную, затем `VERCEL_PROJECT_PRODUCTION_URL`, затем локальный адрес. [Конфигурация Vercel](https://vercel.com/docs/project-configuration/vercel-json)

## Стек и структура

Next.js 16 App Router, React 19, JavaScript и JSX, Sass и SCSS Modules, Zustand, next-intl и IndexedDB. Проверки выполняют Vitest, ESLint, Stylelint и Prettier.

| Каталог                         | Ответственность                                            |
| ------------------------------- | ---------------------------------------------------------- |
| `src/app`                       | Статические маршруты, провайдер локали и SEO               |
| `src/components`, `src/modules` | Переиспользуемые элементы и игровые экраны                 |
| `src/sections`, `src/widgets`   | Секции страниц и оболочки интерфейса                       |
| `src/scss`                      | Общие Sass-функции, миксины и брейкпоинты                  |
| `src/game/content`              | Кампании, герои, графы, противники, предметы и изображения |
| `src/game/core`                 | Сюжет, команды сессии, состояние боя и награды             |
| `src/game/minigames`            | Правила барабанов, Blackjack и Dice                        |
| `src/store`, `src/services`     | Снимки состояния, транзакции IndexedDB и схема             |
| `messages`, `public/art`        | Тексты EN/RU/UK и оригинальные иллюстрации WebP            |
| `tests`                         | Тесты правил, прохождения, локалей и сохранений            |

Компоненты, модули, секции и виджеты используют папки PascalCase с `index.js` и, при наличии локальных стилей, `index.module.scss`. Next.js подключает общие Sass-хелперы через `src/scss/_config.scss`. ESLint задаёт формат JavaScript и группы импортов, Stylelint — порядок свойств SCSS, Prettier форматирует JSON, Markdown и SCSS.

На каждом маршруте герой проходит сюжетную сцену, выбирает действие, получает результат и продолжает путь через карту. Игровой движок принимает команду и возвращает следующий снимок. Барабаны, карты и кости используют передаваемый генератор случайных чисел. Анимация барабанов и кинематографичная вставка отображают уже записанный результат.

## Добавление контента

- **Герой.** Добавьте уникальный ID, характеристики, портрет, маршрут, набор символов, способность и джекпот в [heroes.js](src/game/content/heroes.js). Укажите порядок испытаний в [stories.js](src/game/content/stories.js). Добавьте имя, описание, реплики, финал и названия способностей во все три локали.
- **Кампания.** Создайте запись в [world.js](src/game/content/world.js), перечислите локации эпохи и добавьте иллюстрацию и тексты. Свяжите героев с ID кампании. Для кампании с особыми правилами добавьте соответствующие награды и варианты испытаний.
- **Событие.** Объявите узел и его переходы в [stories.js](src/game/content/stories.js). Условие выбора проверяет [story.js](src/game/core/story.js), а последствия применяет [session.js](src/game/core/session.js). У старого узла сохраните ID или добавьте миграцию сохранений.
- **Символ.** Добавьте ID и относительный вес в набор героя, затем перевод в `messages` и WebP с прозрачным фоном в `public/art/symbols/<hero>/<symbol>.webp`. Первый символ набора служит персональным символом джекпота.
- **Артефакт.** Объявите редкость и бонусы в [items.js](src/game/content/items.js), подписи в `messages`, а способ получения в сюжетной награде. Эффекты экипировки рассчитываются в [battle.js](src/game/core/battle.js).

## Сохранения

У каждого героя собственные локация, глава, контрольная точка, здоровье, опыт, инвентарь, экипировка и незавершённое испытание. Монеты, коллекция, достижения и настройки общие. Адаптер IndexedDB обрабатывает команды в транзакциях. Для награды сохраняется ID события, поэтому возврат назад, перезагрузка или две открытые вкладки не выдают её повторно.

В настройках можно экспортировать, импортировать или сбросить сохранение. Импорт проверяет данные и поддерживает миграцию v1 → v2. При импорте и сбросе браузер запрашивает подтверждение.

# Полировка хроники Торина и испытаний

## Что исправлено

- Результат лагерной монеты обещал 18 монет при фактической награде в 12. Результаты игр, экран добычи и механизм начисления теперь используют фактическую конфигурацию награды. Уже полученный предмет не отображается как новая добыча.
- Счёт Монеты судьбы размещён по сторонам, история помещается под полем, правила открываются по кнопке информации. Сохранённый результат определяет сторону после вращения и после перезагрузки.
- Сюжетные и лагерные испытания используют одну адаптивную сетку. Карточка доступного действия целиком запускает его. Заблокированная карточка объясняет условие доступа.
- После обязательного боя показывается отдельная финальная композиция с одним портретом, краткой сводкой добычи и кнопкой перехода к наградам. Для Смога, Азога, Балрога и Паучьей матки настроены отдельные эффекты.
- Все семь глав Торина используют реплики по месту и событиям. Троллий лес учитывает способ прохождения, Город гоблинов учитывает выбор в Ривенделле, Эребор учитывает наличие ключа, а финал учитывает победу над Смогом. Старые незавершённые испытания в Морок-лесе по-прежнему открываются и после результата ведут к обязательному бою.
- Карточка карты сохраняет номер доступной главы. После финала последняя локация отмечена как пройденная.

## Проверки

- `npm test` — 91 тест прошёл. `npm run format:check` и `npm run build` завершились успешно.
- Vitest проверяет выдачу монет, опыта и предметов, в том числе после восстановления из IndexedDB, повтор команд, результат монеты после перезагрузки, сюжетные развилки, обязательных боссов, независимые сохранения и ключи EN/RU/UK.
- В браузере пройдены семь глав Торина. Проверены монета с перезагрузкой посреди броска, дуэль на костях, ручная раздача и раскрытие результата блэкджека, карта с масштабированием и финальные сцены Паучьей матки, Смога и Азога. Ширины проверки 1440, 768 и 375 px. Балрог проверен через конфигурацию сцен и тесты последовательности.
- Для физического телефона и других браузерных движков отдельного прогона не было.

## Ассеты монет

Каждая пара состоит из двух прозрачных WebP 384 × 384 px. Оба файла содержат полный металлический диск, чеканку и рельеф. Тонкая боковая грань отрисовывается средствами CSS.

| Каталог                      | `heads.webp`         | `tails.webp`               |
| ---------------------------- | -------------------- | -------------------------- |
| `public/art/coins/erebor/`   | Золото, гномий молот | Гора и геометрический кант |
| `public/art/coins/shire/`    | Бронза, дуб          | Колосья                    |
| `public/art/coins/gondor/`   | Серебро, Белое Древо | Корона                     |
| `public/art/coins/elven/`    | Серебро, лист        | Звезда                     |
| `public/art/coins/mordor/`   | Тёмный металл, Око   | Руна                       |
| `public/art/coins/numenor/`  | Золото, корабль      | Роза ветров со звездой     |
| `public/art/coins/fallback/` | Металл, компас       | Плетёный узел              |

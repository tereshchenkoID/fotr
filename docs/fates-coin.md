# Fate’s Coin

## События Торина

| Событие                                          | Доступные игры                                                                                         |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Купец Озёрного города                            | Блэкджек, кости, Монета судьбы. Договориться с купцом по-прежнему можно при достаточной репутации.     |
| Необязательное испытание в лагере Тролльего леса | Блэкджек, кости, Монета судьбы. Соперник во всех трёх играх — Балин.                                   |
| Обязательные бои                                 | Смауг, Азог и паучья матка ведут сразу в бой. После поражения можно повторить бой с контрольной точки. |

Карта Трора, диалоги в Ривенделле и способы пройти Троллий лес через бой, отвлечение или артефакт продолжают работать. В остальных хрониках используются существующие конфигурации. Состояния ранее открытых испытаний остаются доступны по старым идентификаторам.

## Движок и сохранения

Граф хранит доступные игры рядом с сюжетными действиями. Экран выбора показывает только разрешённые игры. Если из чисто игровых вариантов доступен один, движок открывает его сразу. Когда у события есть сюжетная альтернатива, интерфейс оставляет её в существующем выборе. В лагере с одной игрой соответствующая кнопка сразу её открывает.

Команда броска содержит номер раунда. Движок принимает один выбор стороны, независимо определяет результат с вероятностью 50/50 и сохраняет выбранную и выпавшую стороны через IndexedDB. Анимация начинается после записи. Счёт и номер раунда восстанавливаются из истории. Загрузка сохранения сразу показывает зафиксированное состояние. Старая команда с тем же номером раунда не может сделать второй бросок.

Единый результат испытания содержит идентификатор события, игру, исход, статистику, награду и следующий узел. Награды определяет граф и выдаёт существующий механизм одноразовых наград. Сохранения остаются версии 3. Новые поля необязательны для прежних файлов. Незавершённые ранние сохранения Dice и Blackjack сохраняют свои прежние обработчики.

В Озёрном городе победа в Монете судьбы стоит 8 монет вместо 12 за другие игры, а поражение оставляет 4 монеты. В лагере выигрыш в Монете судьбы даёт 12 монет вместо 18 за другие игры. Остальные компоненты награды сохраняются. Лагерное испытание по-прежнему доступно один раз за хронику героя.

## Графика

Используются существующие WebP-изображения как рельефы. Трёхмерный корпус, металл, кант и вращение отрисовываются CSS. Реестр содержит пары сторон для Эребора, Шира, Гондора, эльфийских земель, Мордора, Нуменора и запасной темы.

Для замены рельефов можно добавить прозрачные WebP в `public/art/coins/<theme>/heads.webp` и `public/art/coins/<theme>/tails.webp`, где `<theme>` — `erebor`, `shire`, `gondor`, `elven`, `mordor`, `numenor` или `fallback`. Желательны квадратные изображения 256 × 256 с графикой в центральных 80%, без нарисованного корпуса и фона. Пути подключаются в `src/game/content/coin-themes.js`. Гондорский рельеф сейчас использует существующее знамя с Белым Древом. Для монеты можно подготовить отдельную гравировку дерева без полотнища.
